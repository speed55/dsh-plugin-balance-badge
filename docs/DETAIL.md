# 账户余额徽标

在 DeepSeek Harness 侧边栏底部、**设置**上方显示当前登录账户的余额，并在消耗达到阈值时全屏提示，省去打开 `platform.deepseek.com` 查余额这一步。

## 显示什么

- 充值余额（充值钱包）与赠金余额（赠送钱包），按币种分别显示；小数按平台规则保留两位并向零截断，不足一分显示 `<¥0.01`。
- 徽标显示有余额的那个钱包；悬停显示完整明细；点击打开小面板，含明细、更新时间、刷新、**查看用量**、**隐藏此余额**。
- 未登录时显示「未登录」，面板里提示去「设置 → 账户」登录；读取失败显示「不可用」，面板里可重试。

## 消耗提醒

每累计消耗满一个阈值（默认 ¥5，可自行改成 ¥1 等任意值），整屏弹一次提示：

- 全屏撒钱：**红色百元人民币、绿色美元和金币**一起从画面上方落下、翻转、飘散——纸币带票面框线、水印椭圆、中央符号与角上的「100」，随下落做 Z 轴翻面；同时中央的 `−¥5.00` 放大砸入并轻微震动，背后扩散一圈光环，屏幕有一层暖色光晕。
- 下方一行「余额 ¥45.20 · 本次已用 ¥12.70」；落下的张数由「撒币密度」滑块决定——**默认 0 即稀疏（12 张）**，拉到 100 是密集（150 张）。
- 约 2.4 秒后自动消失；整层 `pointer-events: none`，不拦截点击、不抢输入焦点。
- 一次观测跨过多档时合并成一条（如 `−¥10.00` + 「连续 2 档」），不会连播。
- 页面切到后台期间的消耗，切回来时补播一条「离开期间 −¥X」的汇总。
- 首次读数、切换币种、以及离开不足一档的零头对账都不播报。
- 徽标本身同时脉冲一次；`prefers-reduced-motion` 下只保留中央金额的淡入淡出，不撒钱、不震动。
- **金币音效**：撒钱同时播放一段金币声，两段素材可切换，**均由作者原创**：
  - **收银机 cha-ching**：1.3 秒，两次清脆的收银机响铃后自然衰减，最像"奖励到账"；
  - **金币掉落**：1.4 秒，连续掉落的金币声，最像"一把金币撒下去"。
  两段素材由作者自己制作，经裁切 → 高通去隆隆 → 软限幅 → 抗混叠降采样到 22.05 kHz 单声道 16-bit 后，以 base64 内嵌在客户端代码里（处理管线见 `assets-src/process_samples.py`）。播放时解码一次，单档播一层、多档叠第二层微失谐副本。浏览器无法解码时自动退回振荡器合成的兜底音色。

阈值与读取间隔都在「设置 → 通用 → 消耗提醒」里：三个快捷档位（¥1 / ¥5 / ¥10）、一个可填任意值的自定义输入框、**撒币密度滑块（稀疏 ↔ 密集，实时显示会落下多少张）**，以及余额读取间隔选择（10s–300s）。**阈值越小，读得越勤**才看得到「一次一档」的节奏——把阈值降到 ¥1 时建议同时把间隔调到 20–30 秒。

同一条控制行末尾的 **「预览」** 按钮会立刻按当前阈值播一次提示（不扣任何额度、不需要等消耗），用来调字体、时长和渐晕浓淡；它不受「消耗提醒」和「显示余额」两个开关限制。

## 开关

- 「设置 → 通用 → 显示账户余额」：控制侧边栏徽标，关掉后徽标消失并停止一切余额读取。
- 「设置 → 通用 → 消耗提醒」：只控制全屏动画，可以「看着余额但不要动画」。
- 「设置 → 通用 → 消耗音效」：只控制声音，可以「要动画但静音」；同一行的「音效」两个按钮切换使用哪段素材，右边的「预览」按钮可以立刻试听。

两个偏好都由 Host 侧保存（持久化在本 profile 的 `cordis.patch.yml` 里），改动即时生效、刷新页面和重启应用都不会丢。侧边栏面板里的「隐藏此余额」是同一个徽标开关的快捷入口。

## 数据来源与限制

- 余额来自 Harness 内置账户插件已登录的凭证：浏览器调用 `remote.account.getBalance`，Host 侧完成鉴权与校验，**账户 token 不会进入页面**，本插件也不要求任何 API key。
- 页面可见时按配置的间隔刷新（默认 60 秒）；从其它窗口切回时也会补读一次。
- **「最近使用量」没有官方接口**：Platform 只提供余额查询，用量明细只能在其页面查看。因此「查看用量」是一键跳转（新标签打开 `usageUrl`），本插件不抓取、不逆向平台的用量接口。
- 全屏提示只在页面打开时出现；页面关着期间没有任何进程在观察余额。

## 已知边界

- 侧边栏收起成窄栏时只显示钱包图标，金额在悬停提示与无障碍名称里。
- 若账户插件未组合或未登录，徽标降级为「未登录 / 不可用」，不影响 GUI 其它部分。
- 平台侧非消费性的余额下降（退款撤销、赠金回收）也会触发一次提示；它只是提示，不改动任何数据。
